Install Aplikasi di Android

Jalankan full-screen tanpa address bar browser

Perangkat Android Anda mendukung instalasi langsung 1-klik ke layar utama!

Cara Install Manual di Chrome Android:
1

Buka halaman aplikasi ini menggunakan browser Google Chrome di HP Android Anda.

2

Ketuk ikon Menu Titik Tiga (⋮) di pojok kanan atas browser Chrome.

3

Pilih "Install aplikasi" atau "Tambahkan ke layar utama", lalu konfirmasi Install. Ikon PetaTrack akan muncul di laci aplikasi Android Anda.

APK Builder (Paket Android)

Unduh source code & konfigurasi siap kompilasi menjadi file .APK

Opsi 1: Buat File .APK Online (Tanpa Coding / Tanpa Android Studio)
  1. Unduh file index.html di atas, lalu upload ke hosting gratis seperti GitHub Pages, Vercel, atau Netlify.
  2. Buka situs pwabuilder.com, masukkan URL aplikasi Anda, lalu klik Package for Stores → Android untuk mengunduh file .apk siap install.
Opsi 2: Build APK Native via Capacitor CLI 
mkdir petatrack-android && cd petatrack-android
npm init -y && npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init "PetaTrack PDF" "id.petatrack.gps" --web-dir=www
# Salin index.html ke folder www/ dan timpa AndroidManifest.xml
npx cap add android && npx cap sync
cd android && ./gradlew assembleDebug

File APK hasil build tersedia di: android/app/build/outputs/apk/debug/app-debug.apk
